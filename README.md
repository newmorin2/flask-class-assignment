# Flask Contact Form

## Description

This is a simple Flask web application that allows users to submit a contact form.
After submitting their details, users are redirected to a thank-you page confirming
that their message has been received.

## Features

* Contact form with user input fields
* Thank-you confirmation page
* Simple and easy-to-use interface
* Built using Flask and HTML

## Technologies Used

* Python
* Flask
* HTML
* CSS

## How to Run

1. Clone or download the project.
2. Install Flask.
3. Run the application.
4. Open your browser and visit the local URL displayed in the terminal.
